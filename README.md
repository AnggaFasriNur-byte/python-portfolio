# Python Portfolio

A professional collection of Python projects focused on Data Extraction, Web Scraping, and Automation. This repository demonstrates the progression of scraping techniques from parsing static HTML to automating complex interactions on dynamic, anti-bot protected websites.

## Current Projects

### Web Scraping

#### 1. IMDb Advanced Search Scraper (Advanced)
Automated web scraping pipeline to extract 1,000+ movie metadata records from IMDb's Advanced Search platform. Bypasses strict anti-bot protections and handles lazy-loading pagination.
- Technologies: Python, Selenium, Undetected-Chromedriver, BeautifulSoup4, Pandas, Jupyter Notebook, Excel

#### 2. E-Commerce Books Scraper (Intermediate)
Extracts detailed book catalog data (titles, prices, ratings, availability) from an e-commerce platform and structures it into a clean, ready-to-analyze dataset.
- Technologies: Python, Requests, BeautifulSoup4, Pandas, Jupyter Notebook, Excel

#### 3. Career Market Intelligence (Foundational)
Collects Python job market data directly from Python.org Jobs, including automated data cleaning for job titles and location formatting.
- Technologies: Python, Requests, BeautifulSoup4, CSV

#### 4. Product Market Insight (Foundational)
Collects product information from mock e-commerce websites to build foundational skills in HTML parsing and market analysis data gathering.
- Technologies: Python, Requests, BeautifulSoup4, CSV
